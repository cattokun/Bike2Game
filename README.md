# Bike2Game

Bike2Game turns an exercise bike with a Bluetooth cadence sensor into a Windows game controller.

It can convert pedaling into:

- Virtual Xbox-compatible controller input
- VRChat OSC movement
- W-key input

## Website

https://bike2game.pages.dev/

## Features

- Bluetooth Low Energy cadence sensor support
- Virtual gamepad output
- VRChat OSC support
- Keyboard movement mode
- 7-day trial
- One-time license

## Requirements

- Windows 10 or Windows 11
- Bluetooth Low Energy adapter
- Compatible cadence sensor
